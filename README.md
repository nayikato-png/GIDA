# Hello GiDA

เลขาส่วนตัวสำหรับเวรพยาบาล ประกอบด้วย ตารางเวร ค่าเวร แผนเวลาเรียนและวิจัย Diary และ Mood tracker

เป็นเว็บแอปไฟล์เดียว ไม่ต้อง build ข้อมูลทั้งหมดเก็บไว้ในเครื่องที่เปิดใช้ (localStorage) ไม่ได้ส่งขึ้นเซิร์ฟเวอร์

## Deploy บน GitHub Pages

1. สร้าง repository ใหม่บน GitHub เช่น `hello-gida`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (index.html, runtime.js, sw.js, manifest.webmanifest, icons/, stickers/, .nojekyll)
3. ไปที่ **Settings → Pages** เลือก Source: **Deploy from a branch**, Branch: `main` / `(root)` แล้วกด Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/hello-gida/`

> อย่าอัปโหลดไฟล์ `gida-backup-*.json` ขึ้น repository เพราะมีตารางเวรและ Diary ส่วนตัว

## ติดตั้งบนไอโฟน

1. เปิดลิงก์ด้วย **Safari**
2. กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** → เพิ่ม
3. จะได้ไอคอน GiDA เปิดแบบเต็มจอเหมือนแอป และใช้งานได้แม้ไม่มีเน็ต (หลังเปิดครั้งแรก)

## ย้ายข้อมูลเดิมเข้ามา

เปิดแอปจากไอคอนบนหน้าจอโฮม → แท็บ **ฉัน** → **สำรองข้อมูล** → **นำเข้า** แล้วเลือกไฟล์ `gida-backup-*.json`

## ข้อควรรู้

- ข้อมูลอยู่ในแอปบนหน้าจอโฮมของเครื่องนั้นเท่านั้น (แยกจาก Safari) ถ้าลบแอปออก ข้อมูลจะหายด้วย กด **สำรอง** เดือนละครั้ง แล้วเก็บไฟล์ไว้ใน iCloud Drive
- เวอร์ชันนี้ใช้ AI อ่านรูปตารางเวรไม่ได้ ใช้ปุ่ม **แก้ไข / กรอกเอง** ในแท็บปฏิทินแทน
- ลงปฏิทินด้วยปุ่ม **ดาวน์โหลดไฟล์ปฏิทิน** (.ics) แล้วกด "เพิ่มทั้งหมด" ในปฏิทินไอโฟน

## เปลี่ยนไอคอน
